# BlogScope 네이버 글쓰기 도우미 (크롬 확장)

BlogScope 원고 화면의 **🚀 네이버로 보내기**를 누르면, 내 크롬에서 네이버 블로그 글쓰기 창을 열고
제목·본문을 채워 넣습니다. **발행 버튼은 직접** 눌러 내용을 확인한 뒤 발행하세요.

## 설치
1. 크롬 주소창에 `chrome://extensions`
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 `extension` 폴더 선택
4. BlogScope 화면 새로고침(F5) → 설정 탭에 '● 설치됨' 표시

## 동작
- 네이버에는 내가 로그인한 크롬 그대로 접속합니다(아이디·비밀번호를 저장하지 않음).
- 글쓰기 창 오른쪽 위에 안내 배너가 뜹니다. 자동 입력이 안 되면 **[제목 넣기] [본문 넣기]** 또는 **[본문 복사] 후 Ctrl+V**.
- '작성 중인 글이 있습니다' 같은 네이버 안내 창이 뜨면 먼저 닫고 버튼을 누르세요.
- 원고는 30분 동안만 유지되고, 한 번 넣은 원고는 새로고침해도 다시 자동 입력하지 않습니다.

## 주의
- 네이버 스마트에디터 구조가 바뀌면 자동 입력이 실패할 수 있습니다. 요소 선택 규칙은 `naver.js` 의 `SEL` 에 모아 두었습니다.
- 자동으로 발행 버튼을 누르거나 여러 글을 연속 게시하는 기능은 넣지 않았습니다(네이버 정책상 제재 위험).
